# Среднеазиатский Фонд Социально-Правовой Поддержки

Помощь трудовым мигрантам в России и их семьям.

Сайт: https://vsvld778.github.io/safspp-website/

Восемь языков: русский, английский, таджикский, узбекский, казахский, кыргызский, белорусский и хинди. Выбор языка — кнопки с флагами в шапке; доступные названия и состояние выбранного языка.

Полное название справа от знака «Открытая дверь». Оформление построено на бирюзовых и изумрудных архитектурных арках, тёплом светлом фоне, золотых и гранатовых акцентах.

Форма создает личный черновик и позволяет скачать TXT; обращение не передается на сервер. PDF-концепция — на русском языке.

GitHub Pages: main, корневая директория. HTML со встроенными CSS, JS и переводами; изображения в assets/.
