# Среднеазиатский Фонд Социально-Правовой Поддержки

Помощь трудовым мигрантам в России и их семьям.

Сайт: https://vsvld778.github.io/safspp-website/

Семь языков: русский, английский, таджикский, узбекский, казахский, кыргызский, белорусский. Полное название справа от знака «Открытая дверь». Дизайн основан на бирюзовых и изумрудных архитектурных арках с золотыми и гранатовыми акцентами.

Форма создает личный черновик и позволяет скачать TXT; обращение не передается на сервер. PDF-концепция доступна на русском языке.

GitHub Pages: main, корневая директория. Статический HTML со встроенными CSS, JS и переводами; изображения в assets/.
